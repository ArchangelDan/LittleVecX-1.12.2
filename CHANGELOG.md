
## 1.1.0

### Added
- Added a HEX field to color pickers.
- Added a rotatable placement preview for Rotation structures in the Industrial Recipe, with a configurable rotation step and precise Mark Mode positioning.
### Fixed
- Fixed a NullPointerException when activating an elevator cabin.
### Changed
- Removed the old color copy and paste buttons in favor of the HEX field.
- Removed the unused elevator passenger stabilizer and obsolete roadmap note.

## 1.0.1
- Added the Optimize large blueprint previews option for optimizing previews of large blueprints. When enabled, LittleVecX disables the red invalid-placement overlay whenever LittleTiles switches to low-resolution mode. This prevents major FPS drops caused by fully processing large blueprints solely for the red preview.
