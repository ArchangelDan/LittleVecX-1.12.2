# LittleVecX 1.12.2

An addon for the LittleTiles Minecraft mod (1.12.2), built through its open/public API classes rather than a fork or mixins, extending its functionality for the old game version. It adds an Industrial Recipe with multi-selection, a flexible animation system (multi-scenario, overlay, checkpoint, and loop animations), a full-featured multi-floor elevator with signals, and a set of extra structures (storage, wallpaper, furniture).

Also serves as a preview of some ideas for *LittleVecX 1.21.1*, a larger, not yet released addon for newer LittleTiles versions.

Originally started as a personal tool for my own 1.12.2 build, then set aside for a long while as development moved to newer LittleTiles versions — later finished up and released for anyone still building on 1.12.2.

## Requirements

Forge **14.23.5.2855**; CreativeCore **v1.10.71**; LittleTiles **v1.5.87**.
